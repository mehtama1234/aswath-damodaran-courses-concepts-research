Concept

Real options

Meaning. Managerial flexibility embedded in projects: the option to expand, abandon, delay, or adapt as uncertainty resolves.

Why it matters. Real options matter when static NPV misses the value of learning and future choice.

How Damodaran develops it. The Celsius and post-mortem material uses real options to show when uncertainty can create value rather than merely risk.

Common mistakes

  • Calling every uncertain project an option.
  • Double-counting option value already embedded in cash-flow forecasts.
