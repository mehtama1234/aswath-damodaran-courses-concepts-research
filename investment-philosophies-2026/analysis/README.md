# Investment Philosophies 2026 Analysis

This folder is the first synthesis layer on top of the transcript corpus in
`../raw-material/youtube/`.

Current corpus baseline:

- course: `Investment Philosophies - The 2026 Edition`
- instructor: `Aswath Damodaran`
- videos with transcripts: `43`
- indexed words: `138,353`
- indexed cues: `41,884`

## Files

- `project-objective.md`: end-to-end target for what this course workspace is
  supposed to become
- `course-thesis.md`: long-form course thesis source for the generated thesis
  page
- `concepts.json`: structured concept registry for the course-level idea system
- `session-briefs.md`: plain-English per-session brief map for the full course
- `themes-and-subthemes.json`: first-pass detailed theme tree with evidence

## How to use this layer

Use `session-briefs.md` when you need a quick view of what each class session is
doing and how the course arc develops over time.

Use `themes-and-subthemes.json` when you need a more reusable research shape:

- major course themes
- subthemes inside each theme
- societal, cultural, consumer, business, and industrial lenses
- evidence sessions to revisit in the transcript corpus

Use `project-objective.md` when you need the full standard for what this course
should eventually cover across transcripts, themes, subthemes, concepts,
societal/cultural interpretation, and downstream applied analysis.

Use `course-thesis.md` when you need the long-form course argument in source
form rather than only the rendered thesis page.

Use `concepts.json` when you need the reusable concept layer rather than only
reader-facing HTML pages. It keeps the course's major ideas in structured form
for later cross-course comparison and downstream writeup work.

## What this first pass establishes

This course is not just a survey of stock-picking tactics. It is a structured
argument about:

- why investors need a coherent philosophy instead of isolated tricks
- how views on risk, value, growth, information, and timing create different
  investing styles
- why investor psychology and institutional structure shape market outcomes
- why active investing is alluring but hard to sustain
- how passive investing and alternatives fit into the modern investing system
